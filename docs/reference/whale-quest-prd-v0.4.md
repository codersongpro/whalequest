# Whale Quest PRD v0.2
## 네이버 웨일 연계 수업·형성평가·게임형 학습 플랫폼

- 문서 상태: Draft for Implementation
- 버전: v0.2
- 목적: Codex 구현용 PRD
- 우선 목표: **네이버 웨일 브라우저에 실제 설치 가능한 사이드바 확장앱 + 로그인 없는 학생 참여 + 실시간 수업 운영**
- 기본 언어: 한국어
- 대상: 초·중·고 교사 및 학생
- 운영 원칙: Free-first / No-AI-in-app / Privacy-minimal / Whale-first, Web-based

---

# 1. 제품 개요

## 1.1 제품명

**웨일 퀘스트 (Whale Quest)**

> 수업 중 학생의 상태를 빠르게 확인하고, 즉시 형성평가·게임형 학습·협동 활동으로 연결하는 웨일 기반 수업 지원 플랫폼

---

## 1.2 한 줄 정의

**웨일 브라우저 사이드바에서 교사가 수업 도구를 바로 실행하고, 학생은 로그인 없이 QR·수업코드로 참여하며, 실시간 결과와 학습 상태를 교사 대시보드에서 확인할 수 있는 무료 수업 플랫폼**

---

## 1.3 제품 핵심 철학

1. **수업에서는 학생의 상태를 빠르게 확인한다.**
2. **부족한 학습은 바로 문제와 게임으로 다시 학습한다.**
3. **문제는 개인에게, 성취는 함께 만든다.**
4. **교사는 수업 화면을 떠나지 않는다.**
5. **AI 없이, 결제 없이, 가능한 한 무료로 사용할 수 있게 만든다.**
6. **기존 웨일 교육서비스를 대체하지 않고 수업 흐름 안에서 연결한다.**

---

# 2. 해결하려는 문제

교사는 수업 중 다음 작업을 반복한다.

- 학생 랜덤 뽑기
- 모둠 구성
- 활동 시간 관리
- QR 공유
- 이해 여부 확인
- 간단한 형성평가
- 학생 질문 수집
- 결과 확인
- 부족한 개념 재학습
- 게임형 복습
- 다른 웨일 교육서비스로 이동

현재는 여러 사이트와 도구를 오가야 하므로 수업 흐름이 끊긴다.

Whale Quest는 이 작업을 **웨일 사이드바 하나**에서 시작할 수 있게 한다.

# 4. 핵심 운영 원칙

## 4.1 반드시 실제로 동작해야 하는 것

초기 버전은 목업이 아니라 다음이 실제로 동작해야 한다.

### 웨일 브라우저
- `whale://extensions`에서 설치 가능한 확장앱
- 웨일 오른쪽 사이드바에서 Whale Quest 실행
- 사이드바에서 수업방 생성
- 사이드바에서 주요 수업도구 실행
- 필요 시 Web App을 새 탭으로 열기

### 학생 참여
- 로그인 없음
- 회원가입 없음
- 이메일 없음
- QR 또는 6자리 수업코드
- 닉네임 입력 후 즉시 참여

### 실시간
- 교사가 수업방 생성
- 학생이 입장하면 교사 화면 참여자 수 증가
- 학생 응답이 교사 화면에 즉시 반영
- 협동 레이드 진행 상태 실시간 공유

### 대시보드
- 참여자 수
- 응답 수
- 전체 정답률
- 문제별 정답률
- 개념 태그별 정답률
- 협동 게임 진행 상태

# 6. 웨일 생태계 연계 전략

Whale Quest는 기존 웨일 서비스를 복제하지 않는다.

## 6.1 웨일 클래스

역할:
- 수업 자료
- 과제
- 학생 관리
- 클래스 운영

Whale Quest 연계 방식:
- 사이드바에서 웨일 클래스 사용 중 Whale Quest 동시 사용
- Whale Quest 안에 `웨일 클래스 열기` 바로가기 제공
- URL 기반 연결 우선
- 직접 데이터 API 연동은 MVP에서 제외

---

## 6.2 팀보드

역할:
- 공동 작업
- 협업 결과물
- 토론 및 게시

Whale Quest 연계 방식:
- 수업 중 활동 후 `팀보드에서 이어하기`
- 팀보드 링크를 교사가 저장 가능
- QR 만들기를 통해 팀보드 링크 배포 가능

---

## 6.3 웨일온

역할:
- 원격수업
- 화상수업

Whale Quest 연계 방식:
- 웨일온 수업 중 사이드바에서 Whale Quest 실행
- 원격 학생도 동일한 수업 코드로 참여
- 대면/원격 환경 공통 사용

---

## 6.4 웨일 UBT

역할:
- 정식 평가
- 진단/단원/서·논술형 평가

Whale Quest 역할:
- 수업 중 즉시 확인
- 가벼운 형성평가
- 게임형 재학습
- 협동 활동

MVP에서는:
- `웨일 UBT 열기` 링크 제공
- 직접 평가 데이터 연동은 제외

## 목적

# 11. 문제 세트 시스템

# 11.1 원칙

Whale Quest 앱 안에는 AI가 없다.

문제 세트는 다음 방식으로 만든다.

1. 직접 입력
2. 표준 템플릿 붙여넣기
3. JSON 파일 가져오기
4. 외부 AI에서 생성 후 붙여넣기

# 11.5 검증 규칙

가져오기 시 다음 검증 필요:

- `version`
- `title`
- `questions`
- question id 중복
- 지원하는 question type 여부
- 객관식 choices 최소 2개
- answer 범위
- tags 배열
- difficulty 1~3

# 15. 학생 자기주도학습

수업 참여 외에 학생이 **수업방에 입장하지 않고도** 독립적으로 사용할 수 있는 개인 학습 모드를 제공한다.

Whale Quest의 학생 사용 방식은 다음 두 축으로 나눈다.

```text
실시간 수업
수업 코드 / QR
→ 수업방 입장
→ 교사와 함께 활동

개인 학습
문제 세트 선택 또는 가져오기
→ 혼자 학습
→ 오답 복습
→ 게임 학습
→ 개인 기록 확인
```

학생 개인 학습은 로그인 없이도 사용할 수 있어야 하며, MVP에서는 가능한 데이터를 브라우저의 LocalStorage 또는 IndexedDB에 저장한다.

개인 학습 기능은 수업방 상태나 교사 접속 여부에 의존하지 않아야 한다.

---

## 15.1 학생 개인 학습 홈

학생이 수업방에 입장하지 않은 상태에서 Whale Quest에 접속하면 다음 메뉴를 우선 제공한다.

```text
🐋 웨일 퀘스트

오늘 뭐 공부할까요?

🐟 오늘의 복습
최근 틀린 문제와 미완료 문제

🐚 내 문제 세트
직접 만들거나 가져온 문제 세트

🐢 집중 학습
게임 없이 문제 풀이

🐙 오답 다시 풀기
틀린 문제만 재도전

🐬 게임 학습
아케이드 / 타워 디펜스

🐋 학습 기록
최근 학습량과 정답률
```

학생 홈은 교사용 기능을 노출하지 않는다.

---

## 15.2 🐚 내 문제 세트

학생은 자신의 문제 세트를 직접 관리할 수 있다.

입력 방식:

- 직접 문제 작성
- Whale Quest 표준 JSON 붙여넣기
- JSON 파일 가져오기
- 공유 링크 또는 QR로 받은 문제 세트 가져오기

외부 AI를 사용하는 경우:

```text
학습자료
→ ChatGPT / Gemini / Claude 등 외부 AI
→ Whale Quest 표준 문제 템플릿
→ 복사 또는 파일 저장
→ Whale Quest 문제 세트 가져오기
```

Whale Quest 내부에서는 AI API를 호출하지 않는다.

MVP에서는 학생 개인 문제 세트를 브라우저 로컬에 저장할 수 있다.

---

## 15.3 🐢 집중 학습

게임 요소를 최소화한 개인 문제풀이 모드.

주요 기능:

- 문제 순차 풀이
- 한 화면 한 문제
- 진행률 표시
- 정답/오답 확인
- 선택적 해설 표시
- 완료 후 정답률 제공

중·고등학생도 부담 없이 사용할 수 있는 미니멀한 UI를 사용한다.

서버 없이 로컬 문제 세트만으로 동작할 수 있어야 한다.

---

## 15.4 🐙 오답 다시 풀기

학생이 틀린 문제를 자동으로 오답 목록에 추가한다.

기본 흐름:

```text
오답 발생
→ 오답 목록 저장
→ 다시 풀기
→ 정답 시 확인 완료
```

상태 예시:

```text
wrong
→ retry
→ correct
→ mastered
```

MVP에서는 단순 규칙 기반으로 구현한다.

AI 분석은 사용하지 않는다.

---

## 15.5 🐟 오늘의 복습

최근 학습 기록에서 다시 볼 문제를 자동으로 구성한다.

예:

```text
오늘의 복습

최근 틀린 문제      5
아직 안 푼 문제     4
반복 오답 문제      3

총 12문제
```

MVP 추천 규칙:

1. 최근 오답 우선
2. 반복 오답 우선
3. 미완료 문제 포함
4. 최근 정답 문제 일부 제외
5. 하루 최대 문제 수 설정 가능

모든 판단은 로컬 학습 기록을 기반으로 하며 AI를 사용하지 않는다.

---

## 15.6 🐬 아케이드 개인 학습

학생은 자신의 문제 세트를 선택한 뒤 혼자 아케이드 게임을 실행할 수 있다.

흐름:

```text
내 문제 세트
→ 아케이드 선택
→ 문제 풀이
→ 정답 시 전진/에너지
→ 결과
```

실시간 서버 없이도 동작할 수 있어야 한다.

---

## 15.7 🪸 타워 디펜스 개인 학습

학생 혼자 플레이 가능한 전략형 게임 모드.

기본 구조:

```text
문제 정답
→ 자원 획득
→ 방어시설 설치/강화
→ 웨이브 진행
```

MVP에서는 P2로 두되 Question Engine을 공유하도록 설계한다.

---

## 15.8 🐋 탐험 모드

장기 자기주도학습을 위한 성장형 모드.

예:

```text
수면
→ 산호초
→ 심해
→ 해구
```

학습 활동을 통해 탐험 포인트를 얻고 지역을 개방한다.

중요 원칙:

- 학습량을 장식/탐험 진행과 연결
- 유료 아이템 없음
- 경쟁 우위 제공 없음
- 협동 레이드 공격력 등 실시간 경쟁 성능에는 영향 없음

MVP에서는 P2로 둔다.

---

## 15.9 🐋 학습 기록

로그인 없는 MVP에서는 브라우저 로컬 기록을 이용한다.

표시 항목:

- 최근 풀이 문제 수
- 정답률
- 문제 세트별 진행률
- 최근 오답 수
- 태그별 정답률
- 연속 학습 일수
- 오늘 학습량

예:

```text
이번 주

문제 풀이       126
정답률           84%
연속 학습         4일

잘하는 개념
✓ 분수 계산

다시 볼 개념
△ 문장제
△ 광합성
```

장기 기록을 위한 계정/클라우드 동기화는 MVP 범위에서 제외한다.

---

## 15.10 문제 세트 공유 학습

교사는 수업방을 만들지 않고도 문제 세트만 학생에게 공유할 수 있어야 한다.

흐름:

```text
교사
문제 세트 선택
→ 공유 링크 또는 QR 생성

학생
링크/QR 열기
→ 문제 세트 확인
→ 집중 학습 / 아케이드 / 오답 복습
```

이 방식은 실시간 수업방과 독립적으로 동작한다.

공유 문제 세트 사용 시 학생 로그인은 요구하지 않는다.

MVP 구현 방식은 다음 중 하나를 선택한다.

1. 짧은 공유 코드 기반 서버 저장
2. 압축된 데이터가 포함된 공유 URL
3. 정적 JSON 파일 링크

구현 복잡도와 무료 운영성을 고려해 가장 단순한 방식을 우선한다.

---

## 15.11 개인 학습 데이터 저장 원칙

우선순위:

1. LocalStorage / IndexedDB
2. 필요 시 최소 서버 저장
3. 계정 기반 동기화는 추후

로컬 저장 대상:

- 최근 학습
- 오답 목록
- 문제별 상태
- 태그별 학습 통계
- 개인 설정

주의:

브라우저 데이터를 삭제하면 개인 기록도 사라질 수 있음을 UI에서 안내한다.

---

## 15.12 개인 학습 성공 기준

MVP에서 최소 다음이 가능해야 한다.

- [ ] 수업방 없이 학생 홈 접속
- [ ] 문제 세트 직접 가져오기
- [ ] 집중 학습 실행
- [ ] 오답 자동 저장
- [ ] 오답 다시 풀기
- [ ] 오늘의 복습 생성
- [ ] 개인 아케이드 실행
- [ ] 최근 학습 기록 확인
- [ ] 브라우저 재접속 후 로컬 학습 기록 유지

# 44. 최종 방향

Whale Quest는 웨일 클래스나 웨일 UBT를 다시 만드는 서비스가 아니다.

**웨일 브라우저를 중심으로 수업 중 필요한 작은 도구, 실시간 학생 참여, 형성평가, 게임형 재학습, 대시보드를 하나의 흐름으로 연결하는 수업 허브**다.

제품의 핵심 사용 장면은 다음이다.

> 교사가 웨일 클래스에서 수업을 진행하는 도중 오른쪽 Whale Quest 사이드바를 열고, 학생 상태를 확인하고, 바로 문제를 풀리고, 부족한 개념을 협동 레이드로 다시 학습한 뒤 결과를 대시보드에서 확인한다.

이 경험은 실제 웨일 브라우저에서 안정적으로 동작해야 한다.
