# 개발 기록 — 2026-10-01

v0.6: 사용자 수정계획 원본 보관, 예선/본선 구분 제거, 상황 인식 L2 중심으로 코드/문서 조정. 사용 AI는 이 대화의 개발 도구와 위임 작업자이며, 실제 사람 검토가 이루어진 것으로 허위 표기하지 않는다.

주요 작업 지시 요약: 3유형 공통 엔진/IndexedDB/집계 내보내기, 개인학습/검수/완료카드, 익명인증/RPC·비공개SQL 초안, URL모드/교사·학생·레이드·전달물 통합. 외부 문제생성용 전체 프롬프트는 packages/core/exports.ts의 questionPrompt에 있다. 앱 내부 AI API 호출은 없다.

정적 검토에서 부스시간만료·UBT 경로우회·수업오답 개인복습연결·만료방 표시를 발견해 수정했다. 실제 테스트 범위는 VERIFICATION.md에 기록한다. SQL은 실행/사람 보안 검토 전 초안. 예제 교육과정코드/사실성·외부AI2종 출력·실제사람 검수 지점은 수행후 증거를 추가한다.

검토/수정 중 단순 오류: JSX 괄호·radio 메뉴 선택자·홈앵커 라우팅을 수정해 타입/브라우저 검사를 통과시켰다. 이전 테스트 실패를 숨기지 않고 최종 재실행 결과로 판단한다.
