# 구현 기준과 제품 방향

2026-10-01 기준. 사용자 승인 제작 계획과 이후 방향 정리를 요약한 문서다. **설계 문서이며 구현 완료 목록이 아니다.** 구현 상태는 HANDOFF와 VERIFICATION을 확인한다.

## 제품과 공모전 방향

웨일 사이드바에서 실시간 수업 도구를 운영하고 웹앱의 개인 학습과 공통 문제 엔진으로 연결한다. 첫 완성 범위는 수업 기능 + 개인 학습이다. 개인 학습은 개발 순서가 뒤지만 첫 버전의 필수 조건이다. 한 학급 30~50명, 동시 활성 수업방 1개부터 검증한다.

사용자 제공 NWEC 2026 화면의 분야 1: 수업 지원·학습 활동에 맞춘다. 다른 교사가 쉽게 쓰는 활용성, 반복 업무 감소, 웨일 교육서비스와 자연스러운 연결, 학년·교과 범용성을 우선한다. 접수·심사 조건 전체 검증 및 출품은 아직 하지 않았다. AI API 사용은 필수가 아니며 앱 내부 AI를 추가하지 않는다.

## 핵심: 오늘의 수업

도구 모음에서 더 나아가 한 수업의 활동 순서·안내·진행 상태를 이어 주는 구조를 목표로 한다.

1. 순서·시간·안내·문제 세트·외부 링크를 포함한 수업 흐름 저장, 복제, 재사용.
2. 교사가 활동 시작/종료, 시간/순서 변경, 추가/건너뛰기를 결정. 자동 다음 활동 전환은 하지 않는다.
3. 학생은 한 번 입장한 같은 수업방에서 현재 활동·안내·시간·모둠·수행 행동·도움 요청·완료 상태 확인. 외부 활동 후 돌아오는 안내 제공.
4. 교사는 응답/질문 결과를 보고 복습 활동을 선택하고 수업 종료 요약을 저장.

예시: 사전 체크 3분 → 클래스 자료 7분 → 팀보드 12분 → 퀴즈/레이드 13분 → 마무리 5분. 선택 가능한 예시이며 모든 도구를 강제하지 않는다. 외부 활동에는 URL 외에 목적·안내·시간·모둠 링크가 필요하다.

| 활동 | 완료/결과 근거 |
|---|---|
| 자체 퀴즈·투표·레이드 | 서버가 확인한 실제 제출·결과 |
| 클래스 자료 읽기·팀보드 | 공식 API가 없으면 학생 자기 보고 또는 교사 확인 |
| 웨일 UBT | 교사 종료 확인; 추후 결과 파일 가져오기 |
| URL 열기 | 학습 완료 근거가 아님 |

OAuth는 API 사용 권한을 뜻하지 않는다. 비공식 API·크롤링·자동 동기화를 하지 않는다. 추후 UBT/Excel 가져오기는 실제 샘플 파일 검증이 먼저다. 파일에 문제 본문/해설이 없을 수 있다. 복습 연결은 교사가 교육과정 요소를 Quest 문제 세트에 매핑하며, 이름만으로 학생을 자동 매칭하지 않고 교사가 확인한 코드를 사용한다. **UBT 가져오기·학생 매핑·맞춤 수업 생성은 현재 Phase 1 범위가 아니다.**

후속 개인화는 확인된 태그를 기반으로 힌트·기본·도전 문항을 제공하는 방향이며 고정 능력반을 만들거나 정오답만으로 오개념을 추론하지 않는다. 개인 로컬 기록이 자동으로 교사에게 공유되는 것으로 설계하지 않는다.

## 기술과 권한

- React + TypeScript + Vite; apps/web, apps/extension, packages/*.
- 정적 웹은 Vercel 설정, 실시간은 Supabase, 개인 문제/기록은 IndexedDB. 서버 없는 기능은 서버에 의존하지 않는다.
- 사이드바는 수업 제어·간단 도구, 복잡한 편집·분석은 웹, 학생 홈은 수업 참여와 혼자 학습 구분. 전자칠판에는 집계만 표시한다.
- MV3 sidebar_action을 사용하고 action과 함께 선언하지 않는다. 게임은 React/SVG/CSS, 공통 엔진이 채점한다.
- 내부 익명 세션과 서버의 소유/참여 관계로 교사·학생 권한을 판단한다. 6자리 코드는 입장 수단일 뿐 관리 권한이 아니다.
- 학생은 자기 응답만 제출하고 정답 사전 조회/다른 학생 답안 조회를 차단한다. 전자칠판은 별도 집계 읽기 권한.
- 확장앱 → 대시보드 권한 전달은 단기 일회용 코드. 장기 세션 토큰을 URL에 넣지 않는다. 테이블/실시간 채널에도 권한 검사, 서버 비밀 키는 브라우저에서 제외.
- 학교 공동 IP 50명의 익명 인증을 실제 시험하고 제한/남용 방지 설정을 함께 검증한다. Supabase 한도/가격은 구현 시 공식 문서 재확인.

## 문제와 실시간 상태

- QuestionSet JSON 1.0 유지. 객관식은 선택지 인덱스, OX는 불리언, 단답은 허용 정답 목록.
- 단답은 유니코드·앞뒤 공백 정규화. 동의어/수학적 동치는 작성자의 허용 답안으로 지정.
- 학생 제출은 활동 ID·문제 ID·실제 답안·제출 ID·풀이 시간. 학생이 correct/점수를 지정하지 않는다. 신원/태그와 채점은 서버에서 확인.
- 서버/로컬은 같은 채점 규칙. 가져오기는 문항별 오류를 보여 주고 확인한 정상 문항만 저장.
- 방에 현재 활동 1개, 활동 ID/출제 회차로 늦은 제출 차단. 중복 방지, 답안 저장·통계·HP 변경은 트랜잭션.
- 재접속은 서버 snapshot/버전으로 동일 참여자 복구. 미확인 제출은 전송 대기.
- 레이드 정답 동일 기여량, 학생별 동일 문항 기여는 활동당 1회. 오답 후 정답도 기여. 기본 5분, 목표 HP는 시작 인원×문항 수의 70% 정답 달성량으로 계산.
- 개인 순위/콤보 배율 없음. 집계 상태는 최대 초당 1회 배치, 화면에서 보간. 학생에게 개별 답안 전체를 전파하지 않는다.

## 개인 학습과 보존

- 집중 학습·오답 복습·오늘의 복습·개인 아케이드·내 문제 세트. 로컬 기록에 문제 세트 버전+문제 ID 저장.
- 오늘의 복습은 최근 오답 → 반복 오답 → 미완료, 기본 20문항·중복 제거. 재도전 정답은 복습 완료, 다시 오답은 오답 목록 복귀.
- 공유는 서버의 읽기 전용 세트 짧은 링크/QR, 기본 30일 만료. 가져온 사본/기록과 교사 원본에는 영향 없음.
- 방 생성 24시간 만료, 원시 응답은 종료/만료 24시간 뒤 삭제. 교사가 필요한 요약을 로컬 저장.
- 개인 기록은 기기/브라우저 로컬, 계정 간 동기화 없음. 삭제 안내·JSON 백업/복원 제공.

## 검증과 납품

문제 검증/채점·복습·통계 분모·기여량·만료 단위 테스트; 권한 우회/다른 방/정답 조회/점수 조작/중복/종료 후 제출 통합 테스트; 교사1+학생3 수업 E2E와 개인 학습/재시작 E2E; 30/50명 동시 입장/제출·공동 IP·단절 복구·무료 한도 시험; 웨일/Chrome/Edge/360px 모바일/전자칠판 검증.

코드 발급 2초, 입장 20초, 일반 집계 1초는 측정 목표이며 실제 측정 없이 달성으로 쓰지 않는다. 레이드 배치 지연은 따로 기록한다.

최종 납품: 소스·확장앱 빌드·웹 배포 설정·DB 마이그레이션·예제 2종·설치/운영 안내·검증 기록. 공개 배포/스토어 등록은 시범 운영 이후 별도다. 타워 디펜스·탐험·성장·OAuth·학교 연계는 후속 버전이다.
