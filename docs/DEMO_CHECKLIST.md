# 시연 환경과 체크리스트 (v0.6)

목표3분, 실제 웨일3회 연속 완주. 현재는 로컬 브라우저 경로 검증이며 공식서비스 게시/웨일 실기기 완주는 아직 아니다.

## 준비

- 시연용 클래스/팀보드 공간을 교사가 미리 만들고 로그인 상태를 확인한다. 앱은 계정을 만들거나 내용을 자동 게시하지 않는다.
- 교사 클래스/팀보드 주소를 실제 시연 공간으로 설정한다. 시연 시작은 별도 방/체험번호3명. 시연 탭 열기는 사이트를 새 탭으로 열며 팝업 차단 시 각각 열기 버튼 사용.
- VITE_PUBLIC_APP_URL을 빌드에 지정해 iframe 저장소 접근용 앱 호스트 권한을 포함한다. 설치된 웨일에서 교사 웹/사이드바 데이터 공유를 확인한다.
- 실제 휴대폰 사용은 서버 연결 이후. 20명 행사장 공동IP/예비데이터망/오프라인 영상 준비.

## 흐름

- [ ] 클래스탭 → 클래스모드 → 공지 복사 → 교사가 게시
- [ ] 자료탭 → 수업모드 → 수업방/입장QR → 이해도/형성평가
- [ ] 웨일온/칠판 → 원격모드 → 집계/3문항 레이드
- [ ] 활동종료 → 팀보드탭 → 방금 오답카드 이미 준비 → 복사/이미지 게시
- [ ] 학생 종료후 오답복습준비 → 정답 재도전 → 완료PNG → 직접 클래스 제출
- [ ] 클래스탭 → 복습문안/오답기반 다음차시 추천
- [ ] 실제 수업적용 집계 차트. 미수집 데이터는 제시하지 않음

## 대체/정리

- 자동인식 실패: 사이드바 상단 클래스/팀보드/원격/수업 수동 탭. 네이티브 웨일온은 수동 경로 사용.
- UBT: 보수적 도메인잠금, 수동모드로 우회되지 않아야 함.
- 네트워크/로그인 실패: 준비한 시연 영상, 예비 휴대폰 데이터. 로컬데모를 휴대폰 실시간 성공으로 설명하지 않음.
- 부스: 종료 후 오답카드, 30초 새방. 중지버튼과 종료/정리 확인. 여러 시작 클릭/이전방 정리는 운영 전 점검.
- 게시한 시연 공지/팀보드 카드/임시과제는 교사가 직접 지우고 원래 상태로 복구한다. 실제 학생 방/자료를 삭제하지 않는다.
