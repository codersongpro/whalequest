# Whale Quest 페이즈별 제작 기준

근거: 제공된 PRD v0.4 파일, 2026-09-30 승인 계획, 페이즈별 구현 요청.
PRD의 본문 버전 v0.2는 파일명과 불일치한다. 원본은 유지하고 이 문서에서 개인 학습도 첫 완성 버전의 필수 조건으로 명시한다.

| 페이즈 | 범위 | 완료 기준 |
|---|---|---|
| 1 · 현재 | React/TypeScript/Vite 기반, 실제 MV3 웨일 사이드바, 웹 주소 저장·새 탭 연결, 최소 한국어 UI, 설치 안내 | lint·타입·빌드·UI 테스트, 실제 웨일 확장앱 로딩·390/590px·연결 확인 |
| 2 | 오늘의 수업 로컬 흐름 저장·복제·교사 수동 진행 + 랜덤 뽑기, 모둠, 타이머, QR | 서버 없이 순서·시간·안내·외부 활동 문맥 및 설정 유지 |
| 3 | Supabase 익명 세션, 권한, 수업방·입장·종료·재접속·현재 활동 안내 | 교사 1명·학생 3명, 같은 코드로 활동 이동, 타인 방 접근 차단 |
| 4 | 이해도 체크, 투표, 기본 집계 | 활동 전환·개인 응답 비공개 |
| 5 | 공통 문제 엔진, 편집·가져오기, 빠른 확인·형성평가 | 3유형 채점·문항/태그 통계 |
| 6 | 협동 레이드·전자칠판·결과 | 동시 제출·중복 방지·대표 수업 흐름 |
| 7 | 개인 학습·오답·복습·아케이드·공유 | 방 없이 학습·기록 복원 |
| 8 | 질문함·룰렛·결과 저장·외부 링크·접근성 | 30~50명 부하 및 한 학급 실사용 |

각 페이즈의 검증 결과와 저장소 반영을 보고한 뒤 멈춘다. 사용자의 다음 페이즈 요청 전에 후속 기능 구현을 시작하지 않는다. Phase 6은 중간 수업용 버전이며 Phase 8까지 전체 제품 완료로 부르지 않는다.

## 수업 흐름 중심 방향

기능은 오늘의 수업을 중심으로 묶는다. 교사가 다음 활동을 결정하며 학생은 같은 방에서 현재 안내와 진행을 확인한다. 외부 활동의 URL 열기는 완료 근거가 아니다. 상세 기준은 [IMPLEMENTATION_PLAN](IMPLEMENTATION_PLAN.md)에 있다. 이 변경은 후속 작업 설계이며 실제 흐름 저장/진행 기능은 아직 없다.

## 공모전 방향

사용자가 제공한 NWEC 2026 화면을 기준으로 **분야 1: 수업 지원·학습 활동**에 맞춘다.

- 활용성: 다른 교사도 README와 예제만으로 실행할 수 있어야 한다.
- 수업 루틴 개선: 상태 확인 → 형성평가 → 협동 복습 → 결과 확인의 화면 이동을 줄인다.
- 웨일 연계: 웨일 클래스 등 수업 페이지를 유지한 채 사이드바를 사용한다. URL 바로가기와 실제 데이터/API 연동을 구분한다.
- 범용성: 학년·교과를 문제 세트 데이터로 분리하고 초6 수학/중2 과학 예제로 검증한다.
- 앱 내부 AI나 유료 API를 추가하지 않는다. 스크린샷에서는 특정 AI 기술 사용이 필수가 아니라고 안내한다.

공식 공모전 접수·심사 조건 전체를 검증한 것은 아니다. 공모전 제출이나 배포는 이 작업에 포함되지 않는다.
