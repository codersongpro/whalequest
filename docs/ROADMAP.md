# 최종 산출물 구현 순서 (v0.6)

예선/본선 구분과 관문A/B를 없애고 [v0.6](reference/whale-quest-plan-v0.6.md)의 한 최종 산출물을 따른다. 사용자 최신 요청에 따라 전체 범위를 함께 구현했으며, 프로젝트가 없어 브라우저 시연/연결 준비와 운영 완료를 구분한다. 단계별 조건을 통과했다는 뜻이 아니다.

| 단계 | 코드/준비 상태 | 실제 완료 조건의 남은 부분 |
|---|---|---|
| 1 준비 | 타입·원본·실행 안내 | 주최 허용/도메인·사전 설문·성취기준 확정 |
| 2 사이드바·상황 인식 | URL 규칙·MV3·수동모드·iframe·UBT 잠금 | 실제 웨일 서비스 탭/새창/주소 변경·사이드바 유지 |
| 3 수업 도구 | 타이머·명단·랜덤·모둠/수정·QR | 실제 사이드바 닫기/모드전환 영속성 확인 |
| 4 수업방 | 동일 브라우저 방·학생탭·만료·교사제어; 서버RPC 준비 | 익명 인증·RLS·기기간 참여·서버 복구/전송 대기 연결 |
| 5 활동·평가 | 3유형 엔진·검수·이해도/투표/평가·교사 통계 | 서버 정답 사전조회/조작/권한 통합 시험 |
| 6 레이드 | 5분·HP·기여/중복 제한·집계화면·첫시도 오답 | 실제 트랜잭션·50명 동시 제출 |
| 7 전달물·연계 | 로컬보관함·공지/카드/이미지·복습추천·원격/UBT모드 | 실제 클래스/팀보드 게시·평가 경로·확장 저장소 공유 |
| 8 개인학습 | IndexedDB·복습·완료PNG·시연공유/QR·백업/복원 | 서버 공유30일·공식 성취기준·실기기 장기 기록 확인 |
| 9 현장마감 | 질문/결과저장·4예제·설치/시연 안내 | 교사5분 사용성·관리자 실제 배포·예제 정답/코드 검수 |
| 10 수업적용 | 측정 항목/기록 안내 | 서로 다른2학급 각각3차시·결과/수정 보고서 |
| 11 시연완성 | 시연 데이터/서비스 탭묶음·부스 반복·체크리스트 | 실제 서비스계정·3회완주·20명 부스·영상 |

일반 수업의 다음 활동은 교사가 결정한다. 부스만 종료 후 카드/30초 새방 반복을 자동 수행한다. 실제 수업 적용은 서버/연계가 준비된 후 시작하며 데이터/권한 미완료 시 시연을 운영으로 쓰지 않는다. 상세 남은 작업은 REMAINING_WORK.md.
