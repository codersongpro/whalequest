## 웹 E2E 확인 범위

- 소개 화면·앵커·브라우저 예외, 360/390/590/1280px 화면 넘침·첫 Tab 탐색.
- 같은 브라우저의 학생 3개 탭 입장 → 이해도 체크 → 형성평가 → 레이드 → 오답 전달물/PNG → 클래스 복습 추천 → 학생 본인 기록의 개인 복습.
- 개인 3유형 학습 → 완료 PNG → 새로고침 후 이력/오답 유지.
- 교사 360/390/590px, 수동 UBT 잠금, iframe에서 학생/부스 경로로 이동해도 UBT 잠금 유지.
- 검수 확인 후 읽기 전용 공유 세트의 로컬 사본 가져오기.
- 같은 버전인 다른 방으로 전환, 공유 토큰 변경 시 이전 세트·확인 상태 제거, 부스 종료 후 원래 타이머가 만료돼도 30초 재시작 유지.

마지막 세 회귀 사례는 수정 전 3/3 실패를 재현했고 수정 후 전체 검사에서 3/3 통과했다. 정적 재검토에서도 세 수정 지점을 확인했다. 타이머 검사는 Playwright 가상 시계로 진행했으며 실제 부스 리허설과 구분한다.

## 실기기·운영 환경의 남은 검증

- 설치된 웨일 4.39.410.14의 `npm run test:whale`은 확장 비활성 기본 인수를 제외한 뒤에도 시작 단계 Target closed/프로세스 exit 0으로 실패했다. worker/page 로드 전이며 실제 확장 설치·사이드바 확인 성공이 아니다. 원인은 아직 특정하지 않았다.
- 웨일 서비스 탭의 자동 상황 인식·수동 우선·UBT 잠금·iframe/웹탭 저장소 공유·사이드바 유지·390/590px는 실제 웨일에서 확인해야 한다.
- 현재 수업방/공유는 동일 브라우저 로컬 시연이다. 학생 3개 탭 검사는 기기간 실시간, 운영 권한 보호 또는 서버 부하 증거가 아니다.
- Supabase 프로젝트가 없다. 서버 계약 테스트는 모의 HTTP이며 SQL은 실행하지 않은 초안이다. 실제 익명 인증·RLS·정답 비공개·채점 트랜잭션·실시간·재접속·공동 IP 30/50명은 미검증이다.
- 클래스 공지 게시·팀보드 카드 게시·완료 카드 제출·웨일온 화면 공유, 공식 성취기준 검수, 외부 AI 2종 출력 검증은 미완료다.
- Chrome·모바일·전자칠판 실기기, 2개 학급 각 3차시, 20명 부스, 3분 시연 3회 및 측정 결과는 없다.
- Vercel 공개 배포·원격 CI 통과·스토어 등록은 확인하지 않았다. CI 정의 또는 로컬 빌드는 그 증거가 아니다.

상세 실행 항목은 [남은 작업](REMAINING_WORK.md), 다음 작업자는 [handoff](HANDOFF.md)를 따른다. 실제 검증 범위를 넘어서 전체 운영 완료라고 표현하지 않는다.
