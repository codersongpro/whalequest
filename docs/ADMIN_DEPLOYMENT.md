# 관리자 배포 준비

현재는 설치용 로컬 빌드·설정 안내이며 실제 학교 관리자 일괄배포 성공을 검증하지 않았다.

1. 학교 정책과 웨일 관리자 문서에서 확장 배포 허용/방법을 확인한다. 스토어 등록은 범위 밖이므로 개발자 설치를 기관 정책과 혼동하지 않는다.
2. 배포된 웹 기본주소·검증된 확장ID·Supabase 서울프로젝트/익명 세션/RLS/50명 제한을 확정한다.
3. 학생은 웹 링크, 교사는 필요시 확장. VITE_PUBLIC_APP_URL을 빌드하고 host_permissions가 서비스5호스트+자체앱1호스트로 제한됐는지 확인한다. tabs/content_scripts 없음.
4. 웹 frame-ancestors를 설치 확장ID로 제한하고 사이드바 iframe/웹탭 저장소 및 단기 교사 권한 전달을 검사한다.
5. 교사1+학생3 시범 → 공동IP30/50명 → 기기별 권한/종료/정리/복원 → 배포대상 확대.
6. 학생 번호/별명, 공용PC 로컬잔류·JSON백업/삭제, 응답보존/공유만료 정책을 학교에 안내한다.

관리콘솔 설정값·자동 설치 명령을 확인 없이 지어내지 않는다. 실제 학교별 배포 절차/실행 결과를 이 문서에 추가한다.
