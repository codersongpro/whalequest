# 빠른 시작 — 브라우저 시연

1. Node22.12+ 설치 후 npm ci, npm run dev. http://127.0.0.1:5183 → 교사 수업.
2. 시연 시작을 누르면 체험학생3명이 준비된다. 직접 학생 역할을 하려면 학생 화면 열기로 같은 브라우저 새 탭에서 번호/별명으로 참여한다.
3. 이해도 체크 시작 → 학생 응답(또는 시연 응답 채우기) → 활동 종료. 형성평가/레이드도 현재 활동을 끝내고 시작한다.
4. 레이드5분, 정답 동일기여/순위없음. 종료 뒤 팀보드 모드에 오답3문항 카드가 자동 준비된다. 텍스트 복사/PNG 저장 후 교사가 직접 팀보드에 게시한다.
5. 클래스 모드에서 공지/복습문안을 복사하고 오답복습세트를 저장한다. 학생은 종료후 내 수업 오답 복습 준비 → 오늘의 복습 → 완료 카드PNG를 다운로드/클래스 과제 제출한다.
6. 백업·설정에서 JSON 백업/복원/명시적 삭제. 공용PC에 기록이 남을 수 있으므로 삭제 확인.

**휴대폰은 아직 연결되지 않는다.** QR은 로컬 시연 주소이며 실제 다중기기 연결은 Supabase 준비/검증 뒤 가능하다. 시연학생 응답과 실제 학습 효과를 구분한다.

확장: npm run build → 웨일 whale://extensions → 개발자 모드 → '압축해제된 확장 프로그램 로드' → dist/extension 선택 → 웨일 오른쪽 사이드바에서 '웨일 퀘스트' 아이콘 클릭. 웹앱이 확장앱 안(app/)에 포함되어 별도 배포·주소 입력 없이 사이드바에서 바로 동작한다(시연 모드, 같은 브라우저). 외부 배포 웹앱을 쓰려면 사이드바의 '연결 설정'에서 HTTPS 주소를 저장하고 VITE_PUBLIC_APP_URL로 빌드한다. Chromium 로드·사이드바 iframe 렌더는 확인했으나 실제 웨일 사이드바 버튼 동작과 서비스 탭 자동 전환은 웨일에서 직접 확인해야 한다.
